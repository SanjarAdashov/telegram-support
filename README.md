# Telegram-агент поддержки

MVP-бот для Telegram:

- определяет язык клиента через подключённый ChatGPT;
- ищет смысловое совпадение вопроса с FAQ на любом языке;
- переводит найденный канонический ответ на язык клиента;
- если уверенного ответа нет, создаёт обращение и уведомляет оператора;
- оператор отвечает через `/reply <номер> <текст>`;
- пользователь или оператор закрывает обращение через `/close` или `/close_ticket <номер>`;
- каждая заявка и вся история сообщений сохраняются в PostgreSQL;
- FAQ-автоответы тоже создают отдельную заявку;
- сотрудник может ответить из админки, после чего ответ сохраняется и отправляется клиенту в Telegram;
- пользователи и подключённые группы видны в отдельном разделе админки, где их можно добавить в чёрный список;
- заблокированные пользователи и группы получают фиксированное сообщение о нарушении политики и не создают новые заявки;
- база знаний FAQ хранится в PostgreSQL и редактируется через веб-админку.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID и впишите его в `OPERATOR_IDS`.
3. Скопируйте `.env.example` в `.env` и заполните значения.
4. Установите зависимости и запустите:

```bash
uv sync
uv run python bot.py
```

Для PostgreSQL создайте базу `support_bot` и укажите строку подключения в `.env`:

```env
DATABASE_URL=postgresql://postgres:пароль@localhost:5432/support_bot
ADMIN_PASSWORD=надёжный_пароль_админки
```

Запуск админ-панели:

```bash
uv run uvicorn admin_app:app --host 127.0.0.1 --port 8000
```

Откройте [http://127.0.0.1:8000/admin/faq](http://127.0.0.1:8000/admin/faq), войдите с `ADMIN_PASSWORD`. Раздел заявок доступен по адресу [http://127.0.0.1:8000/admin/requests](http://127.0.0.1:8000/admin/requests), пользователи и группы — по адресу [http://127.0.0.1:8000/admin/users-groups](http://127.0.0.1:8000/admin/users-groups). Таблицы `faq_items`, `support_requests`, `support_messages` и `telegram_entities` создаются автоматически при первом запуске.

Запуск Telegram-бота:

```bash
uv run python bot.py
```

Тесты:

```bash
uv run pytest -q
```


## Использование в группах

Добавьте бота в группу и напишите сообщение с его упоминанием:

```text
@имя_бота Какие у вас часы работы?
```

В группе бот намеренно игнорирует сообщения без упоминания, чтобы не отвечать на весь поток чата. Ответ отправляется реплаем на сообщение пользователя. Если ответа в базе нет, автор получает сообщение на своём языке, а вопрос сохраняется для оператора.


Бот вызывает установленный `hermes chat`, поэтому использует уже подключённую в Hermes авторизацию и текущую модель ChatGPT. Отдельный OpenAI API-ключ для бота не нужен. Переменная `HERMES_MODEL` необязательна: без неё используется активная модель Hermes.

ChatGPT выполняет две операции: определяет язык и смысловой FAQ-категории вопроса, затем переводит канонический ответ из базы на язык клиента. Само содержание ответа берётся из базы знаний, а не генерируется с нуля.


FAQ-пункты теперь редактируются через админ-панель. Бот получает активные записи из PostgreSQL перед каждым запросом, поэтому изменения вступают в силу без изменения кода.

## Telegram Mini App админ-панели

1. Разверните админ-панель по HTTPS на публичном домене.
2. Укажите в `.env` полный HTTPS-адрес Mini App:

```env
ADMIN_MINI_APP_URL=https://admin.example.com/admin/miniapp
ADMIN_SESSION_SECRET=длинный_случайный_секрет
ADMIN_COOKIE_SECURE=true
```

3. В разделе «Сотрудники» сохраните Telegram ID сотрудника в поле «Telegram ID сотрудника».
4. После команды `/start` бот показывает кнопку «Открыть админ-панель» только пользователю, чей Telegram ID найден в таблице `employees` и не заблокирован.
5. Пользователям без записи сотрудника кнопка не показывается.

Mini App не доверяет данным JavaScript: сервер проверяет Telegram Web App `initData` через HMAC с токеном бота, затем сопоставляет подписанный Telegram ID с PostgreSQL и только после этого создаёт админ-сессию. Роль берётся из базы данных.

`127.0.0.1` и обычный HTTP не являются рабочим URL для Telegram Mini App; для реального Telegram-клиента нужен HTTPS.

## Важно

Локальные тесты не проверяют подключение к Telegram API. Для live-проверки нужен настоящий токен BotFather.
